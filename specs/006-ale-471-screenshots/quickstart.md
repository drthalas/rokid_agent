# Validation
Run targeted Node screenshot tests and affected approval/integration tests. Run the explicitly authorized `node scripts/screenshot-smoke.mjs --authorized` once a coherent candidate exists. It uses an isolated gateway fixture and native policy, Calculator and connected Gmail, creating two unsent self-addressed drafts. It must record real image hashes/dimensions, visible50, DRAFT/MIME readback, no send, cleanup and unchanged approvals. Stop on real human denial; provision macOS Screen Recording through owner settings only if needed. Release/deploy/physical tests are a separate phase.
