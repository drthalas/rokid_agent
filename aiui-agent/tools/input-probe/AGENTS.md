# RV101 Input Probe

Diagnostic package for ALE-461, not the final Jarvis product build. Open pages/index/index without a task.
Nine automatic test windows collect only event code/edge/relative milliseconds/repeat and numeric test step.
No microphone, speech recognition, network, credentials or Codex calls. No production session/storage keys changed.
After all tests, results cycle on HUD and remain in agent-local rokid-input-probe-v1 storage.
During capture only, Backspace default is intercepted to observe double taps without closing the probe;
during review Backspace retains native exit. System AI gestures may hide the page and may deliver no key.
